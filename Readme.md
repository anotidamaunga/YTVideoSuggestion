# YTVideoSuggestion

A streamlit app that turns an uploaded document into a concise summary and a ranked list of related YouTube Videos, using embeddings and cosine similarity

The general idea of the project is:
User uploads lecture slides or any other material and the app will:
1. Generate a summary of the document 
2. Extrac the most important subject specific terms
3. Search Youtube for videos based on those terms.
4. Rank the videos by the how similar to the document they are combined with the amount of views
